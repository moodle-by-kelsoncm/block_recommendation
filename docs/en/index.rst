Overview - moodle-block_recommendation
======================================

**moodle-block_recommendation** is a Moodle block plugin designed to display custom HTML content blocks (announcements, banners, recommendations, and important links) on the site front page or user dashboard.

Key Features
------------

- **Rich Text Editor (HTML)**: Configure dynamic rich content directly within the Moodle interface.
- **Strategic Display Locations**: Optimized for Front Page (``site-index``) and Dashboard (``my``).
- **Mustache Templates**: Rendering powered by Mustache (``recommendation.mustache``) for clean visual consistency.
- **Multi-language Support**: Native translations for Brazilian Portuguese (pt_BR) and English (en).

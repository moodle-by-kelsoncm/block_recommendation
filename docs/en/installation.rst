Installation
============

Requirements
------------

- **Moodle**: 4.1 or higher (requires Moodle version 2022112800 or higher)
- **PHP**: 8.0, 8.1 or higher

Installation Steps
------------------

1. Navigate to your Moodle blocks directory:

   .. code-block:: bash

      cd /path/to/moodle/blocks

2. Clone this repository into a folder named ``recommendation``:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/block_recommendation.git recommendation

3. Log in to Moodle as an Administrator.
4. Go to **Site Administration > Notifications** to complete the database upgrade.

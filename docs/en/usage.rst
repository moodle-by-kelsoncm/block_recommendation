Usage Guide
===========

1. Navigate to the Moodle Front Page or user Dashboard (``/my``).
2. Enable **Edit mode** in the top-right corner.
3. Click **Add a block** and select **Recommendation**.
4. In the block action menu, select **Configure Recommendation block**.
5. Add your desired content, banners, or notices using the rich text editor.
6. Save changes to display the block to your users.

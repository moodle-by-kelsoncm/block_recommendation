Configuration
=============

Permissions and Capabilities
----------------------------

- ``block/recommendation:addinstance``: Allows adding a new recommendation block instance.
- ``block/recommendation:myaddinstance``: Allows adding the block to the user dashboard.

Customization Options
---------------------

- Block content is managed within instance configuration and rendered through a Mustache template.
- Supports custom HTML/CSS inserted via the rich text editor or Moodle theme classes.

Configuração
============

Permissões e Capabilities
-------------------------

- `block/recommendation:addinstance`: Permite adicionar um novo bloco de recomendação.
- `block/recommendation:myaddinstance`: Permite adicionar o bloco ao painel do usuário.

Opções de Personalização
------------------------

- O conteúdo de cada bloco é mantido na tabela de dados do bloco e formatado via Mustache template.
- Suporta CSS customizado inserido através do editor HTML ou por classes de tema do Moodle.

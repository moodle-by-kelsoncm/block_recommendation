Instalação
==========

Requisitos
----------

- **Moodle**: 4.1 ou superior (requer Moodle versão 2022112800 ou superior)
- **PHP**: 8.0, 8.1 ou superior

Procedimento de Instalação
--------------------------

1. Acesse o diretório de blocos da sua instalação do Moodle:

   .. code-block:: bash

      cd /caminho/do/moodle/blocks

2. Clone o repositório nomeando a pasta como `recommendation`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/block_recommendation.git recommendation

3. Faça login no Moodle como Administrador.
4. Acesse **Administração do site > Notificações** para concluir a instalação do banco de dados.

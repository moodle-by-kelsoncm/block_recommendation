Guia de Uso
===========

1. Acesse a Página Inicial do site Moodle ou o seu Painel (`/my`).
2. Ative o **Modo de Edição** no canto superior direito.
3. Clique em **Adicionar um bloco** e selecione **Recommendation**.
4. No menu do bloco criado, selecione **Configurar bloco Recommendation**.
5. Insira os textos, banners ou avisos desejados no editor de texto.
6. Salve as alterações para publicar o bloco para os usuários.
